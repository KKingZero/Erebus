# Erebus Exploitation Framework

A custom command-and-control (C2) framework built in Go for AI-driven offensive security operations. Erebus uses a beacon-mode architecture with protobuf-based wire protocols, gRPC operator API, and mTLS-secured communications.

> **For authorized security testing, red team engagements, and research purposes only.**

## Architecture

```
┌──────────────┐         gRPC (mTLS)         ┌──────────────────┐
│   Operator   │◄───────────────────────────►│    Teamserver    │
│   / AI Agent │                             │                  │
└──────────────┘                             │  ┌────────────┐  │
                                             │  │  Sessions   │  │
                                             │  │  Manager    │  │
┌──────────────┐      HTTPS (Protobuf)       │  ├────────────┤  │
│   Implant    │◄───────────────────────────►│  │  Listener   │  │
│   (Beacon)   │                             │  │  Manager    │  │
└──────────────┘                             │  ├────────────┤  │
                                             │  │  Task       │  │
                                             │  │  Dispatcher │  │
                                             │  ├────────────┤  │
                                             │  │  SQLite DB  │  │
                                             │  └────────────┘  │
                                             └──────────────────┘
```

## Features

- **Teamserver** — Central C2 server with gRPC API for operator/AI interaction
- **HTTPS Listener** — TLS-encrypted callback handler for implant beacons
- **Beacon Implant** — Lightweight agent with configurable sleep/jitter intervals
- **Shell Execution** — Remote command execution with structured output
- **Task Queue** — Async task dispatch with optional blocking wait
- **Event Streaming** — Real-time gRPC event stream (new sessions, task results, logs)
- **Session Management** — Track, list, and kill active implant sessions
- **Auto-generated CA** — Built-in certificate authority for mTLS
- **HMAC Authentication** — Implant identity verification via pre-shared secret
- **Cross-platform** — Linux and Windows implant builds
- **SQLite Persistence** — Sessions, tasks, and loot stored locally
- **Plugin Registry** — Compiled-in module system for extending implant capabilities

## Quick Start

### Prerequisites

- Go 1.22+
- `protoc` with `protoc-gen-go` and `protoc-gen-go-grpc` plugins
- `make`

### Build

```bash
# Generate protobuf code
make proto

# Build teamserver
make teamserver

# Build implant (Linux)
make implant

# Build implant (Windows)
make implant-win
```

### Run Teamserver

```bash
./build/teamserver
```

The teamserver starts with defaults:
- gRPC API on `127.0.0.1:50051`
- HTTPS listener on `0.0.0.0:443`
- Data stored in `~/.erebus/`

Override via CLI flags:

```bash
./build/teamserver \
  -grpc 127.0.0.1:50051 \
  -host 0.0.0.0 \
  -port 8443 \
  -secret <hex-encoded-secret>
```

### Build Implant with Custom Config

```bash
make implant \
  CALLBACK_URL=https://your-c2-server:8443 \
  SLEEP_MS=10000 \
  JITTER_PCT=30
```

## Configuration

Config file is auto-created at `~/.erebus/server.yaml`:

```yaml
grpc_addr: "127.0.0.1:50051"
db_path: "/home/user/.erebus/erebus.db"
data_dir: "/home/user/.erebus"
implant_secret: "<auto-generated hex>"
listeners:
  - name: default-https
    protocol: https
    host: 0.0.0.0
    port: 443
```

## Wire Protocol

All communications use Protocol Buffers:

| Channel | Protocol | Auth | Definition |
|---|---|---|---|
| Implant ↔ Teamserver | HTTPS + Protobuf | HMAC-SHA256 | `c2.proto` |
| Operator ↔ Teamserver | gRPC | mTLS | `api.proto` |

## gRPC API

The `ErebusC2` service exposes:

| RPC | Description |
|---|---|
| `StartListener` | Start a new listener |
| `StopListener` | Stop a running listener |
| `ListListeners` | List all listeners |
| `ListSessions` | List active sessions |
| `GetSession` | Get session details |
| `KillSession` | Terminate a session |
| `ExecuteTask` | Dispatch a task to an implant |
| `GetTaskResult` | Poll for task result |
| `ListTasks` | List tasks for a session |
| `Subscribe` | Stream real-time events |
| `GenerateImplant` | Generate implant binary (Phase 2) |
| `ListLoot` | List collected loot |
| `GetLoot` | Retrieve loot item |
